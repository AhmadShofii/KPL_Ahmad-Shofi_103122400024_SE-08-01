## Event Delegation dalam Design Pattern JavaScript

Event delegation adalah salah satu teknik atau pola penanganan event dalam JavaScript, yaitu dengan cara meletakkan event listener pada elemen induk, bukan langsung pada setiap elemen anak. Dengan teknik ini, satu event listener dapat digunakan untuk menangani banyak elemen sekaligus.

Dalam JavaScript, event seperti `click`, `keyup`, `submit`, dan lain-lain biasanya dipasang langsung pada elemen tertentu. Misalnya, jika ada 10 tombol, maka kita bisa saja memasang event listener pada masing-masing tombol. Namun, cara seperti itu kurang efisien, apalagi jika jumlah elemennya banyak atau elemen tersebut dibuat secara dinamis setelah halaman dimuat.

Event delegation memanfaatkan konsep **event bubbling**. Event bubbling adalah proses ketika event yang terjadi pada elemen anak akan naik atau diteruskan ke elemen induknya. Contohnya, jika user mengklik sebuah tombol yang berada di dalam sebuah `div`, maka event klik tersebut pertama kali terjadi pada tombol, lalu naik ke elemen induknya, yaitu `div`, kemudian naik lagi ke elemen yang lebih atas.

Karena adanya event bubbling, kita tidak harus memasang event listener pada setiap tombol. Kita cukup memasang event listener pada elemen induknya, lalu mengecek elemen mana yang sebenarnya diklik.

Contoh sederhana:

```html
<ul id="daftar-menu">
  <li>Nasi Goreng</li>
  <li>Mie Ayam</li>
  <li>Bakso</li>
</ul>
```

Jika menggunakan cara biasa, kita mungkin akan memasang event listener pada setiap elemen `li`.

```javascript
const items = document.querySelectorAll("li");

items.forEach(function(item) {
  item.addEventListener("click", function() {
    console.log("Menu diklik:", item.textContent);
  });
});
```

Cara tersebut memang bisa berjalan, tetapi jika jumlah item banyak, maka event listener yang dibuat juga banyak. Selain itu, jika nanti ada item baru yang ditambahkan melalui JavaScript, item baru tersebut belum tentu langsung memiliki event listener.

Dengan event delegation, kita cukup memasang event listener pada elemen induk, yaitu `ul`.

```javascript
const daftarMenu = document.getElementById("daftar-menu");

daftarMenu.addEventListener("click", function(event) {
  if (event.target.tagName === "LI") {
    console.log("Menu diklik:", event.target.textContent);
  }
});
```

Pada kode di atas, event listener hanya dipasang pada elemen `ul`. Ketika salah satu elemen `li` diklik, event klik tersebut akan naik ke `ul`. Kemudian program mengecek apakah elemen yang diklik adalah `LI` menggunakan `event.target.tagName`.

Bagian penting dalam event delegation adalah `event.target`. `event.target` digunakan untuk mengetahui elemen asli yang menerima event. Jadi, meskipun event listener dipasang pada elemen induk, kita tetap bisa mengetahui elemen anak mana yang diklik oleh user.

Event delegation sering digunakan pada aplikasi web modern karena lebih efisien dan fleksibel. Misalnya pada daftar produk, daftar komentar, menu navigasi, tabel data, atau tombol-tombol yang dibuat secara dinamis dari database.

Contoh lain penerapan event delegation:

```html
<div id="container">
  <button data-action="edit">Edit</button>
  <button data-action="delete">Hapus</button>
  <button data-action="detail">Detail</button>
</div>
```

```javascript
const container = document.getElementById("container");

container.addEventListener("click", function(event) {
  const action = event.target.dataset.action;

  if (action === "edit") {
    console.log("Tombol edit diklik");
  } else if (action === "delete") {
    console.log("Tombol hapus diklik");
  } else if (action === "detail") {
    console.log("Tombol detail diklik");
  }
});
```

Pada contoh tersebut, satu event listener pada `container` dapat menangani tiga tombol sekaligus. Program membedakan tombol berdasarkan atribut `data-action`.

Menurut pemahaman saya, event delegation dapat dianggap sebagai salah satu bentuk design pattern dalam JavaScript karena memberikan pola atau cara yang rapi untuk menyelesaikan masalah penanganan banyak event. Daripada membuat banyak event listener untuk setiap elemen, kita cukup membuat satu event listener pada elemen induk. Pola ini membuat kode lebih sederhana, mudah dirawat, dan lebih hemat penggunaan memori.

Kelebihan event delegation antara lain:

1. Lebih efisien karena tidak perlu memasang banyak event listener.
2. Cocok untuk elemen yang dibuat secara dinamis.
3. Kode menjadi lebih ringkas dan mudah dikelola.
4. Mengurangi penggunaan memori.
5. Memudahkan pengelolaan event pada elemen yang jumlahnya banyak.

Namun, event delegation juga harus digunakan dengan hati-hati. Kita perlu memastikan bahwa event yang ditangani memang berasal dari elemen yang sesuai. Oleh karena itu, biasanya digunakan pengecekan seperti `event.target`, `matches()`, `tagName`, atau atribut `data-*`.

Contoh menggunakan `matches()`:

```javascript
document.addEventListener("click", function(event) {
  if (event.target.matches(".btn-hapus")) {
    console.log("Tombol hapus diklik");
  }
});
```

Kode tersebut berarti program hanya akan menjalankan perintah jika elemen yang diklik memiliki class `btn-hapus`.

Kesimpulannya, event delegation adalah teknik dalam JavaScript untuk menangani event dengan cara memasang event listener pada elemen induk, lalu memanfaatkan event bubbling untuk mengetahui elemen anak yang memicu event. Teknik ini termasuk pola yang penting dalam pengembangan web karena membuat program lebih efisien, fleksibel, dan mudah dikembangkan, terutama ketika berhadapan dengan banyak elemen atau elemen yang dibuat secara dinamis.
